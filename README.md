# 🚀 Machine Learning Mini Projects Suite

A comprehensive collection of real-world **machine learning and data science mini projects** demonstrating practical implementation of:

- Supervised Learning
- Unsupervised Learning
- Natural Language Processing (NLP)
- Time Series Forecasting
- Recommendation & Classification Systems
- Information Retrieval
- Interactive Data Dashboards

This repository is designed as a **portfolio showcase** for recruiters, students, and data science practitioners.

---

## 📌 Projects Included

### 1️⃣ Stock Price Prediction (Time Series Regression)
- Predicts next **3-day stock closing prices** using historical OHLCV data.
- Model: Linear Regression  
- Features: Open, High, Low, Adjusted Close, Volume  
- Evaluation: MSE  
- Tools: `pandas`, `scikit-learn`

---

### 2️⃣ Stock Market Sentiment Analysis (NLP)
- Performs sentiment analysis on Twitter/news text related to stocks.
- Classifies sentiment as **Positive / Neutral / Negative**
- Tool: `TextBlob`
- Application: Market mood analysis for trading insights.

---

### 3️⃣ Company Industry Comparison System
- Compares companies based on:
  - Revenue
  - Profit
  - Market Share
  - Industry
- Uses Pandas aggregation for business intelligence reporting.

---

### 4️⃣ Information Retrieval Search Engine
- Implements a basic document indexing and search system.

- Demonstrates fundamental **IR techniques**.

### 5️⃣ Interactive Business Dashboard (Dash + Plotly)

### 6️⃣ Crime Data Clustering (Hierarchical + K-Means)
- Dataset: US Crime statistics
- Techniques:
  - Data normalization
  - Hierarchical clustering (dendrogram)
  - K-Means clustering + Elbow method
